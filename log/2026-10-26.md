## The hookup

Compiled in only with `+define+WITH_CHECKER` (Icarus: `-DWITH_CHECKER`).
Without it the tb is unchanged and still ALL PASS.

- **Instance:** the checker gets `cdr0`'s aligner `dout`/`pos`, with
  `start` = `cdr_fsm`'s `checker_rst` pulse. `rst_sync` is pulsed with
  `cdr`'s reset at every step.
- **Ports assumed** (§6.6): `wclk`, `rst_sync`, `start`, `dout[7:0]`,
  `pos[2:0]` → `done`, `no_lock`, `errors[15:0]`; parameter `N_BLOCKS`.
- **Module name:** `+define+CHECKER_MODULE=<name>`, default
  `link_checker`. It must not be `checker`, which is a SystemVerilog
  keyword.
- **`+define+CHK_N`:** blocks per step, default 100.

## What it can and cannot compare

The §6.6 line written on 10-23, "`errors` must equal `rx_ref`'s `errors`",
cannot hold per step. The two lock at different moments, so they count
different windows of a jittered link. Corrected in the spec. The tb now
requires:

- **eye interior** (`rx_ref` clean at the step and two either side): lock
  and 0 errors;
- **closed** (`rx_ref` no-lock): no clean lock;
- **centre** of the longest clean run within 1 step of `rx_ref`'s.

Edge steps are reported, not judged.

## Error injection (`+inj=k`)

A checker that never counts errors passes all three checks above. Tried
on a stand-in with its counter removed: ALL PASS. So the tb can now flip
bit 7 of `cnt[7:0]` in every k-th block at the transmitter. Any N-block
window then holds exactly N/k errors. Both counts have that base
subtracted, so "clean" still means 0.

A `cnt` byte is used because the `dout`/`pos` check skips it. `rx_ref`
counts exactly the base at every eye-interior step, and a tb self-check
fails the run if it ever sees fewer.

## Proving the hookup

The checks were run on a throwaway stand-in written from §6.6. It is
kept in the session scratchpad and is not Manuel's design, and not
committed.

| Checker | `+n=20` | `+n=20 +inj=4` |
|---|---|---|
| stand-in | ALL PASS | ALL PASS |
| counter removed | **ALL PASS** | FAIL (under-count at all 248 interior steps) |
| expected `cnt` seeded one low | FAIL | FAIL |
