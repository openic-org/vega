### Why G1's source changed, not only its size

The old text sourced `CONFIG` from "the config table walked out of
`RB_CONFIG_BASE`". Two things are wrong with that:

- `rhd2164_controller` walks the config table **once** after reset and
  never returns to it, so a later table write does not reach the chips.
- Writes injected through sampling entry 32 (MCU diagnostics, §10's
  ZCHECK marker on registers 5–7) change the chips without touching the
  table.

A shadow updated from every `WRITE(R, D)` the SPI master shifts out sees
both paths. It also needs no regbank read port (both are taken, K7). One
MOSI drives both chips, so one byte per register is the whole state.
R-K5 (config done) is now needed by the tunnel: no `CONFIG` before the
walk is finished.
